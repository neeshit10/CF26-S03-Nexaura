**Team:** Nexaura

## Problem Statement
Urban services are interconnected. A failure in one digital or operational service can propagate into other services, creating cascading failures that are difficult to understand with isolated monitoring.

## Solution Overview
UrbanPulse is a software-only prototype that models city services as a dynamic dependency graph and simulates how disruptions propagate across the system.

The prototype focuses on:
- time-dependent infrastructure state
- single and simultaneous failures
- failure propagation
- recovery actions
- cascade depth
- affected services
- recovery time
- reproducible simulation scenarios
- comparison of recovery strategies

## Core Technical Mechanism
The core mechanism is a deterministic graph-based cascade simulation engine.

High-level flow:

```text
Scenario Input
    ↓
Infrastructure Graph
    ↓
Failure Injection
    ↓
Propagation Engine
    ↓
State Updates
    ↓
Metrics Engine
    ↓
Recovery Strategy
    ↓
Comparison / Results
```
